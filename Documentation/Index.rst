----

Embed charts from `Klimadashboard <https://klimadashboard.org>`__
(klimadashboard.de, klimadashboard.at, klimadashboard.org) as TYPO3 content
elements. Editors pick a chart, a region and a design skin; the chart adjusts
its height automatically, needs no HTML rights and sets no cookies.
