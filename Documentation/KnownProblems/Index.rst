==============
Known problems
==============

*   The language setting `en` currently translates only the server-rendered
    snapshot of a chart; the interactive chart is shown in German.
*   Design skins take effect only once they are available on the chosen
    Klimadashboard site.

Report issues at
`GitHub <https://github.com/klimadashboard/typo3-klimadashboard/issues>`__.
